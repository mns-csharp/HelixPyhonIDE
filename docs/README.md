# HelixPython documentation

HelixPython keeps visual tools connected to editable Python source. Designers help users create
and inspect project structure, while the files they generate remain open to direct editing. The
workspace model keeps the Solution Explorer, project metadata, and files on disk in agreement.
Analysis, build, and run commands use that same model so they act on the code users can inspect.

Read these pages in order to understand the product before exploring its advanced features.
